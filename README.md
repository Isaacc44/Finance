# FinansFlow — локальный учёт личных финансов для Android

FinansFlow — собственный минималистичный финансовый менеджер на Kotlin + Jetpack Compose + Room + MVVM. Название, оформление и значки сделаны самостоятельно; логотипы и графические материалы Revius не используются.

## Что есть в первой версии

- Локальная Room-база `finansflow.db`; записи сохраняются после закрытия приложения и перезапуска телефона.
- Главная: общий баланс, доходы, расходы и результат за день/неделю/месяц/год.
- Доходы, расходы и переводы между собственными счетами; редактирование, удаление с подтверждением и копирование операции.
- Целочисленные суммы в узбекских сумах (`Long`), без `Float`/`Double` в денежной модели.
- Начальные категории доходов и расходов, создание пользовательских категорий и счетов; категория может быть удалена без потери истории.
- История с группировкой по датам, поиском, фильтрами по типу, переходом к редактированию.
- Раздел «Работа»: учёт курьерских заказов, суммы, чаевых, бонусов, дат, статистики за день/неделю/месяц. Каждый заказ создаёт обычную доходную операцию, поэтому баланс и общая статистика согласованы.
- Статистика доходов и расходов по категориям.
- Экспорт CSV и полной JSON-резервной копии; восстановление JSON после явного подтверждения. Импорт проверяет структуру, ID и ссылки до замены базы, а замена выполняется в одной транзакции БД.
- Светлая/тёмная палитра следует системной теме Android. Интернет и регистрация во время работы приложения не требуются.

## Открыть и собрать

1. Установить Android Studio с Android SDK 35 и JDK 17 или новее.
2. Открыть папку `FinansFlow` как проект Gradle.
3. Дать Gradle загрузить зависимости и завершить Sync.
4. Запустить конфигурацию `app` на устройстве/эмуляторе либо выполнить `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`). APK после успешной сборки будет в `app/build/outputs/apk/debug/app-debug.apk`.

Проект использует Gradle 8.9, Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Compose BOM 2024.12.01 и Room 2.6.1. При первой сборке необходим интернет для загрузки Gradle, Android SDK и Maven-зависимостей; само приложение после установки работает офлайн.

## Проверка в этой среде

В рабочем контейнере отсутствуют Android SDK, Android Gradle Plugin/Gradle и доступ к скачиванию зависимостей. Поэтому APK здесь не собирался и не запускался на эмуляторе. В проект добавлены unit-тесты расчёта баланса и начала недели; их надо запустить в Android Studio (`testDebugUnitTest`) вместе с полной компиляцией приложения.

## Что ещё не входит в MVP

Это рабочая первая версия ядра, а не полная реализация всего расширенного ТЗ. Пока не реализованы бюджеты и финансовые цели, долги с частичными погашениями, регулярные операции, переименование счетов/категорий, произвольный диапазон дат и сравнение месяцев в аналитике, полный редактор заказов/рабочих расходов, ручной переключатель темы и защита от миграций будущих версий. Перед ежедневным использованием на реальных суммах рекомендуется сначала собрать и проверить проект на своём устройстве.
